Projetos / Renúncias Fiscais em Santos
Projeto de Dados

Dashboard analítico construído para resumir a leitura de uma base pública de beneficiários de renúncias fiscais, com foco em concentração, perfil setorial e tipos de benefício associados a empresas sediadas em Santos.

Categoria: Dados Status: publicado Fonte: Portal da Transparência Federal

Visão geral do projeto

O objetivo deste painel foi transformar uma base pública extensa em uma leitura mais clara, acessível e visualmente organizada, sem simplificar de forma errada a natureza dos dados observados.

O trabalho combina exploração de dados, interpretação metodológica e design de dashboard para destacar concentração, setores dominantes, tipos de benefício e limites do que pode ou não ser inferido diretamente da base.

Telas do projeto

01 / 03

O que o painel entrega

  • Leitura rápida da concentração dos maiores registros da base.
  • Visualização do peso setorial das empresas beneficiadas.
  • Comparação entre tipos de benefício mais recorrentes.
  • Notas metodológicas para separar renúncia fiscal observada de perda direta de arrecadação municipal.

Stack e recursos

Pontos de valor

Recorte territorial claro O painel organiza a leitura especificamente para empresas sediadas em Santos, sem diluir o contexto local.
Leitura metodológica honesta Os blocos explicam o que a base permite afirmar e onde estão os limites da interpretação sobre arrecadação.
Comunicação pública O layout foi pensado para tornar uma base técnica mais compreensível para leitura executiva e apresentação pública.
