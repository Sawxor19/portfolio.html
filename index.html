Sobre

Desenvolvedor focado em Python, automação de processos, IA aplicada e construção de produtos web orientados a dados. Trabalho com foco em resultado: reduzir tarefas manuais, acelerar operação e transformar dados em decisões.

Atuo do problema ao deploy: levantamento de requisitos, desenvolvimento da solução, integração com APIs, modelagem de dados e entrega com documentação clara para facilitar manutenção e escala.

Meu case principal é o E-Clinic, um SaaS para clínicas odontológicas com Next.js, TypeScript, Supabase e Stripe, incluindo autenticação, permissões, financeiro e estrutura multi-tenant.

Cursando Ciência de Dados (conclusão prevista para 2026), com aplicação prática contínua em projetos reais.

O que eu resolvo

O que eu posso construir para gerar ganho real no negócio:

  • Análise de dados com Python e SQL para gerar insights acionáveis
  • Scripts e automações para eliminar tarefas repetitivas do time
  • Dashboards e relatórios para acompanhar operação e desempenho
  • Ferramentas com IA para acelerar atendimento e produtividade
  • SaaS e sistemas web com foco em performance e escalabilidade

Objetivo em todos os projetos: transformar processo manual em fluxo automatizado, mensurável e mais lucrativo.
