Interactive Agrarian Reform

A data-analysis and storytelling project designed to raise public awareness. Built with HTML, CSS, and JavaScript using data from multiple platforms and institutions, including MapBiomas, CPT, IBGE, OBPOPRUA, CAU, INCRA, CAR, and CNIR.

Category: Web Status: published Communication and accessibility

Project overview

The project organizes a dense subject in a friendlier interface designed to make reading, navigation, and comprehension easier for different audiences.

The work involved turning information into a digital experience while maintaining clarity, strong visual hierarchy, and responsive behavior across screen sizes.

What the project set out to solve

  • Bring clarity to long-form content and data distributed across extensive sections.
  • Improve the visual organization of an informational page.
  • Make reading more direct and accessible on the web.
  • Turn information into a more effective digital presence.
